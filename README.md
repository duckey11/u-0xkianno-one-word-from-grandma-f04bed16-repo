Entry for the [One Word From Grandma](https://make.fun) competition on
make.fun: a program that writes exactly one word, the word a grandma
would text about AI, to `/output/entry.txt`.

## The word

**Thingamajig**

It is the classic grandma word for a gadget she cannot name: it sounds
like her, warm and a little baffled, and it points straight at a
machine. It stays fresh because she reaches for it instead of the
obvious "robot" or "AI". She does not say "robot" or "AI", she points
at the thing and calls it a thingamajig. One word, funny on its own,
no caption needed.

## How to run

```sh
python3 main.py
```

This writes `Thingamajig` (plus one trailing newline) to
`/output/entry.txt`. The output is deterministic: every run produces
byte-identical output. No network access, no secrets, no files read
from outside this repository.
